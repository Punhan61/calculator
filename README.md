## Структура проекта (4 раздельных файла)
- `index.html` — главная страница и форма ввода
- `404.html` — страница ошибки 404 с кнопкой возврата на главную
- `style.css` — таблица стилей для всех страниц сайта
- `script.js` — валидация ввода (пусто / буквы / 0 / минус) и независимая история расчётов в `localStorage`
